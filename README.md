# أَدَاة | ADAH

منصة أدوات عربية مجانية، بواجهة RTL متجاوبة وهوية داكنة قرمزية.

## التشغيل
افتح `index.html` في متصفح حديث. لا توجد حاجة إلى تثبيت حزم أو إعداد خادم أو مفاتيح API.

## الأدوات المتاحة
- عداد الكلمات والحروف ووقت القراءة.
- تنسيق JSON والتحقق من صحته.
- مولّد كلمات مرور باستخدام Web Crypto.
- حاسبة حسابية للعمليات الأساسية.
- محول وحدات للطول والوزن ودرجة الحرارة.
- حاسبة العمر.

تتم معالجة مدخلات الأدوات محلياً داخل المتصفح.

## النشر
يمكن نشر الملفات كما هي على Cloudflare Pages باستخدام Direct Upload أو ربط مستودع GitHub. لا يوجد أمر بناء؛ مجلد الموقع هو جذر المستودع.

## ملاحظات قبل الإطلاق العام
- راجع عنوان البريد الظاهر في صفحات السياسات واستبدله بعنوان دعم فعلي تملكه.
- حدّث نطاق الموقع في `sitemap.xml` و`robots.txt` بعد اختيار النطاق النهائي.
- سياسة الخصوصية والشروط مسودتان أوليتان ويجب مراجعتهما قبل الإطلاق.
- لا توجد حالياً إعلانات أو تحليلات أو خدمات تتطلب حساباً.
